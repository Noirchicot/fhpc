# Static dice audio

The four dice throws in this folder come from Kenney's **Casino Audio**
collection:

- Source: https://kenney.nl/assets/casino-audio
- License: Creative Commons Zero (CC0 1.0)
- Original files selected: `die-throw-1.ogg`, `die-throw-2.ogg`,
  `die-throw-3.ogg`, and `dice-throw-3.ogg`

The repository copies are MP3 conversions for broad browser compatibility.
